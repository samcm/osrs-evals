# Brand marks

Generated by `site/game/brands.py`: the agent harnesses' marks. Each file is the source's one-colour
mark with its size, style and colour attributes removed (shape only, square viewBox, no added padding),
for `BrandMark`'s CSS mask. Makers' and inference providers' logos (Anthropic, OpenAI, OpenCode Go …)
are not here: `site/export.py` saves each one in the data from models.dev
(`https://models.dev/logos/<provider id>.svg`, as models.dev serves them) as `data/logos/<id>.svg`.
The game sprite `program.png` (item 21, Cog) stands for the scripted baseline and comes from the game cache
(`site/game/art.ts`); like all game art it is Jagex's, from 2004scape.

Logos and names are trademarks of their owners, used here only to name their products. Their use
here implies no endorsement. Owners' terms: anthropic.com/legal/trademark-guidelines (Claude Code),
openai.com/brand (Codex), opencode.ai/brand, ampcode.com/press-kit.

## Fonts

`../fonts/RuneScape-Bold-12.ttf` (wordmark only): RuneStar/fonts release 1.103-0 (https://github.com/RuneStar/fonts/releases/download/1.103-0/RuneScape-Fonts.zip),
CC0-1.0, the same file rs-world ships in `src/media`. The TTF conversion is CC0; the glyph designs are
Jagex's (`b12_full` in the game cache). Use at 16px or an integer multiple, without smoothing.
